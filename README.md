# JobFit 🎯

JobFit is an AI-powered resume processing and recommendation system designed to match candidates with suitable career opportunities based on their skills and profiles.

## 🚀 Features
* **Resume Extraction:** Parses text from PDF resumes accurately.
* **Skill Identification:** Uses NLP & Named Entity Recognition (NER) to extract candidate skills.
* **Smart Matching:** Classifies candidates and recommends tailored jobs using Machine Learning models.

## 🛠️ Tech Stack
* **Language:** Python
* **Backend:** Flask
* **AI & NLP:** spaCy, NLTK, Machine Learning models (.pkl)
* **Frontend:** HTML, CSS, JavaScript
